# Rock Paper Scissors

A browser-based Rock Paper Scissors game controlled entirely by your webcam. You'll train your own image-classification model in [Teachable Machine](https://teachablemachine.withgoogle.com/), then write the HTML, CSS, and JavaScript to load that model and use it to play against the computer.

## What you're building

The finished project is a single web page that:

- Opens your webcam
- Uses a model you trained yourself to recognize Rock, Paper, and Scissors
- Shows a live confidence bar for each of those classes
- Uses your recognized move to play a round against a randomly-chosen computer move


## Getting Started
You can get started by opening the `directions/` directory and completing each of the parts.
